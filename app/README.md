# X Browser Desktop

Это настольная оболочка X Browser на Electron и Chromium. Вкладки, адресная строка и страницы размещены в одном окне приложения. В интерфейсе можно выбрать панель адреса сверху, снизу или компактно; вкладки сверху или слева; есть сетка всех вкладок, тёмная/светлая тема и адаптация интерфейса под узкое окно.

## Запуск на Windows из исходников

1. Установи Node.js 24 LTS с официального сайта: https://nodejs.org/
2. Открой папку `x-browser-desktop` в Терминале или PowerShell.
3. Один раз выполни `npm install`.
4. Для запуска выполни `npm start`.

Чтобы собрать готовую папку приложения, выполни `npm run package`. Electron Packager создаст её рядом в `x-browser-portable`.

Эта версия бесплатна для локальной разработки. Установка Electron скачает компоненты Chromium и займёт место на диске. Для распространения готового приложения понадобится отдельно собрать установщик.

Компоновка адаптируется к узкому окну, но готовая сборка сейчас только для Windows. Отдельные приложения Android и iPhone требуют своих сборок и публикации через соответствующие магазины. Обычная `index.html` в родительской папке остаётся веб-макетом; для просмотра страниц внутри X Browser запускай настольное приложение.
