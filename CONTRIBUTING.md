# Contributing

Thanks for your interest in X Browser. The project is an early prototype.

## Before contributing

- Discuss substantial changes in a GitHub issue before sending a pull request.
- Do not include API keys, OAuth secrets, certificates, private keys, personal data, or generated installer files in commits.
- Keep browser page content isolated from the Electron UI process. Do not enable Node.js integration in remote pages.

## Pull requests

Use a focused change, describe its effect, and include screenshots for visible UI changes. A maintainer must review and approve changes to build or signing workflows before release.

## Security reports

Do not post credentials or exploit details in public issues. A private security contact will be published before the first public release.
