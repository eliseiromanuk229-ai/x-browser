Подпись кода

Текущая тестовая сборка X Browser не подписана цифровым сертификатом. Она не является релизом SignPath Foundation. Не устанавливай эту сборку, если Windows показывает предупреждение о неизвестном издателе.

Перед выпуском подписанной сборки проект опубликует здесь политику проверки исходного кода, процедуры сборки и подписания, а также сведения о фактическом поставщике сертификата.
